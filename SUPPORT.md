## Questions and bug reports

The current main branch contains no runnable Python exercise files. For a documentation issue or proposal, search existing GitHub issues and open a new issue in [Brajesh31/CODSOFT](https://github.com/Brajesh31/CODSOFT/issues). Include the relevant commit or file path, operating system, Python version if relevant, steps to reproduce, and sanitized output.

Do not attach contact books, exported CSV files, passwords, credentials, or private personal information. Use synthetic examples. This is a volunteer-maintained repository with no paid support or response-time guarantee.

## Third-party software

For Python or Tkinter installation and runtime issues, consult the documentation and support channels for your Python distribution and operating system.
